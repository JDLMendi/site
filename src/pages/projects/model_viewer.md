My internship from last year opened some unique opportunity to how Unity can be used, especially in the University's Virtual Learning Environment **Canvas**. Canvas allows the usage of 'Sharable Content Object Reference Model' or 'SCORM' to integrate materials into the paages to allow customisable interactivities for students to use and learn.

This year, we're using SCORM to integrate our 'Mouse Dissection' proejct into Canvas to help students in the anatomy of the mouse. Though, one of the curiousity was to see if we could use the models we generate from photogrammetry (as they have a large amount of detail) into Canvas. The Model Viewer is a small development tool used to see if these models would behave normally within Canvas.

I say it's a nifty tool to use and might offer some assurance if a model works in Unity (minus the long build time but that's a future me problem).
